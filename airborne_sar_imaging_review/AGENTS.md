# AGENTS.md — airborne_sar_imaging_review 长期执行规则

适用范围：本文件所在目录及其全部子目录。

## 长期规则（必须遵守）
1. 工作顺序固定为：检索 -> 导入 -> 去重 -> 标题/摘要筛选 -> 全文筛选 -> 证据提取 -> 输出清单。
2. 去重优先级：DOI > 标题标准化 > 作者+年份。
3. 原始结果只能保留，不可覆盖删除。
4. 所有不确定信息禁止猜测；无法核实则标记 `UNVERIFIED`。
5. 若多个来源信息冲突，保留冲突并注明来源，不要自行拍板。
6. 所有输出都要可追溯到来源页面或导入文件。
7. 每次批量操作后，在 `00_admin/changelog.md` 中记录日期、动作、影响文件。

## 数据合规约束
- 仅使用合法来源的全文线索。
- 不得虚构 DOI、题名、作者、期刊/会议、年份、卷期页码、摘要、结论、实验指标、参考文献。
- 原始导入结果不可覆盖删除，只能新增版本或保留去重后副本。
